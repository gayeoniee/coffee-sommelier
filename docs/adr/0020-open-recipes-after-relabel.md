# ADR 0020 — 재적재 뒤 오픈판 레시피: 단맛은 로스터리 오프셋(+C), 바디는 해외 매장 표기로 탑재, 공기 게이트 완화는 기각

- 상태: 채택 (2026-09-29)
- 범위: 오픈판 특징 모델(`config/feature_model_open.json`, 유일한 작성자 `scripts/train_feature_model.py`의 `SHIPPED_RECIPES`)과
  ADR 0018 공기 채우기 게이트. 전체판 불변.
- 앞선 결정: [ADR 0019](0019-english-note-aliases.md)가 오픈 DB를 다시 라벨링하고 **같은 레시피**를 다시 학습하자 오픈판 단맛이
  Zenodo 패널(답한 것의 ±1)에서 44.2% → 35.3%로 떨어졌다. 운영에는 싣지 않았다.

## 평가 — [`scripts/eval_open_recipes.py`](../../scripts/eval_open_recipes.py) → [`phase9_open_recipes.json`](../../data/eval/open/phase9_open_recipes.json)
E1 = 로스터리 단위 교차검증(게이지 원두 72개, 대상 로스터리를 늘 뺀 학습), E2 = Zenodo Q그레이더 패널 196샘플(평가 전용). E2는 운영과
같은 분석 경로(`scripts/eval_open_v3.py zenodo`)로, 후보 사양을 모든 게이지 원두에 맞춘 것으로 잰다. 기권 규칙은 ADR 0016의 넷.

### 무엇이 떨어뜨렸나
| 단맛 사양 × 추론 때 매퍼 | E2 답한 85%의 ±1 · MAE |
|---|---|
| 운영 사양(재적재 전 계수) × 이전 매퍼, 재적재 전 DB (운영 수치) | 44.2% · 1.32 |
| 운영 사양 × 이전 매퍼, 재적재 뒤 DB | 46.1% · 1.29 |
| 운영 사양 × 새 매퍼 (영어 노트가 특징으로 들어감) | 43.1% · 1.45 |
| 같은 레시피 재학습 × 새 매퍼 (ADR 0019) | 35.3% · 1.49 |
| 같은 레시피 재학습 × 이전 매퍼 (진단) | 50.3% · 1.25 |

두 가지가 겹쳤다: 패널 카드의 영어 노트("caramel", "nuts")가 이제 `notes_*` 특징이 되어 단맛을 끌어올리고(패널 평균 2.5인데
예측 평균 3.8 → 4.0), 재학습 계수는 노트 특징에 더 기대게 됐다(학습 쪽 노트 특징 변화는 ADR 0017 한국어 별칭 몫 — 영어 별칭을 끄고
학습한 `prev_mapper`는 E1·E2 모두 재학습과 같다). 44.2%는 이전 매퍼 입력 기준이라 새 매퍼 뒤에는 운영 계수도 43.1%다.

다른 기권 규칙(문구 단서 또는 노트 단어, |모델 − 이웃| ≤ 1)은 어느 후보에서도 탑재 규칙보다 E2가 낫지 않다(+C: 45.9%, 48.5%).

## 결정
1. **단맛 = +C** (`SHIPPED_RECIPES["sweetness"] = ("ablation", "+C")`, 기권 규칙 그대로). E2 답한 ±1 **49.7%**(운영 44.2% 이상,
   MAE 1.32 → 1.23), E1 답한 ±1 0.686(운영 당시 0.595, 재학습 0.657) — E1은 나빠지지 않았다. 로스터리 오프셋은 학습 때만 쓰이고
   모르는 원두에는 0이라(런타임도 같다) E1·E2가 런타임 동작 그대로다.
   - **+Bf 기각**: E1이 가장 좋지만 `weak` 특징(노트 단어 약한 라벨)을 런타임 특징 모델이 계산하지 않는다 — E2 50.9%는 그 특징이 0인
     채로 잰 값이고 E1과 다른 모델이다. 쓰려면 런타임 코드가 필요해 이번에는 보류.
   - **노트 특징 빼기 기각**: E2 65.9%지만 E1이 0.657 → 0.514로 잡음(±0.03, 35건 중 1건 = 0.029) 이상 나빠진다.
   - **~B 보정 없는 약한 라벨**: E2 순위상관이 처음으로 양수(+0.33)지만 ±1 43.1%로 기준 미달 — 기록만.
   - 한계: E1 답한 비율이 48.6%로 ADR 0016의 50% 문턱 아래다. 재적재로 이웃 값(10개 중 3개 이상 단맛 라벨) 있는 원두가 줄어서이고
     레시피와 무관하다. 단맛 순위는 여전히 옮겨 가지 않는다(순위상관 음수) — 기권은 정직성 조치 그대로.
2. **바디 = +A wA=1** (`("ablation", "+A wA=1")`, 절제 실험의 진단 행 `~A wA=1`과 같은 설정을 탑재 후보 이름으로 올림). ADR 0016
   규칙(E1 ±1 +0.05, E2 ±1·MAE 안 나빠짐) 대비 이웃 평균(운영):

   | 바디 | E1 ±1 · MAE (n=64) | E2 ±1 · MAE (n=195) |
   |---|---|---|
   | 이웃 평균 (운영) | 0.719 · 0.787 | 0.782 · 0.643 |
   | **+A wA=1 (탑재)** | **0.781 · 0.693** | **0.831 · 0.593** |
   | +A (가중치 0.5) | 0.750 · 0.697 | 0.780 · 0.669 |
   | +A+B+C (절제 실험 최고 E1) | 0.797 · 0.683 | 0.728 · 0.720 |
   | +B · +C | 0.781 · 0.712 / 0.781 · 0.726 | 0.667 · 0.830 / 0.708 · 0.757 |

   +A+B+C는 E2가 나빠져 기각. 가중치(0.25/0.5/1) 셋 중 최고를 같은 E1로 고른 것은 낙관적이다. 바디는 이제 특징 모델 값과 근거 줄
   ("특징 모델 바디 …")을 보이고 속성별 보정 신뢰도(`calibration`, notes=높음 · 나머지 보통)가 이 모델 잔차로 다시 매겨졌다.
   패널 바디는 여전히 "항상 3"(98.5%)을 못 이긴다. 브랜드 원두의 바디(`brands.yaml` `*_open`)는 다시 유도하지 않았다.
3. **공기 채우기 게이트 완화 기각** (ADR 0018의 몫 ≥ 0.2, 3개까지; ADR 0019 뒤 라벨·정답): E1 F1 0.120 → 0.134, 대분류 0.509 → 0.533,
   E2 F1 0.186 → 0.204, 대분류 0.471 → 0.513, 정밀도는 오히려 오름(0.128 → 0.135 / 0.385 → 0.391) — 무너지지 않지만 ADR 0016 막대
   (E1 +0.05)에 못 미친다. 태그 1개 이하 원두는 이미 0.9% / 4.2%라 얻을 것도 적다.
4. **산미 불변**: +B 그대로, E1 0.707 · MAE 0.738, Zenodo 85.7% · 0.54 · 0.71. 재적재 전 계수로도 새 매퍼에서 85.7%라 이득은 입력 쪽이다.
5. `SHIPPED_RECIPES`만 고쳤다(명시적 편집). `eval_open_v3.py`는 이제 탑재 레시피를 따라 E1 잔차·보정을 계산하고
   (`body_shipped` 기록), 절제 실험의 `roaster_offsets`는 이름순으로 써서 설정 파일이 바이트 단위로 재현된다.
   `v3_rows.pkl`(DB 행 캐시)은 재적재 뒤 다시 만든 것이다.

## 덧붙임 (2026-09-29) — 단맛 순위가 패널과 반대인 이유: 두 자료의 "단맛" 관행이 다르다

패널(Zenodo)의 단맛은 5단계 강도 평균으로 우리와 같은 개념이지만, 패널 안에서 단맛은 산미와 강하게 같이 움직이고(Spearman 0.78, n=196) 바디와는 무관하며(−0.04), 로스팅이 밝을수록 높다(라이트 3.10 n=35 · 미디엄 2.26 n=44 · 다크 2.19 n=8). 과일 산미와 함께 느끼는 단맛이다. 오픈판 학습 라벨(국내 로스터리 게이지)은 다크 로스트를 단맛이 높다고 적는다(roasters_kr 다크 4.13 n=15 · 미디엄 2.94 n=33 · 미디엄다크 2.87 n=23 · 라이트 3.75 n=8, 산미와의 상관 0.28) — 캐러멜·초콜릿 계열의 로스팅 단맛이다. 그래서 E2의 단맛 순위상관(−0.32)은 예측기의 오류라기보다 **정답과 라벨이 서로 다른 단맛을 가리키는 것**이고, 어떤 단맛 레시피로도 E2와 E1을 함께 올리기 어렵다(노트 특징을 빼면 E2 65.9%지만 E1 0.514로 무너진 것과 같은 이유).

결정: 앱은 한국 로스터리가 원두 봉투에 적는 관행(로스팅 단맛 포함)을 따른다 — 손님이 실제로 보는 표기와 맞추는 편이 쓸모 있다. E2 단맛 수치는 "관행이 다른 외부 기준"으로만 보고, 대표 수치로 쓰지 않는다. 근거 없는 단맛은 계속 기권한다.
