# ADR 0011 — 로스터리 공개 게이지를 사람 라벨로, 오픈판 속성 예측은 해석 가능한 특징 모델로

- 상태: 채택 (2026-09-28)

## 맥락
오픈 라이선스판(`DATA_VARIANT=open`, 공모전 제출본)은 coffeereview를 뺀 뒤 산미·바디·단맛을 이웃 평균으로만
예측했다([ADR 0009](0009-learned-attribute-model.md)에서 오픈판 학습 모델은 탑재 기준 미달). 그런데 오픈 풀의
라벨은 대부분 CQI의 **품질** 점수(산미 서브스코어 5분위)라 "얼마나 신가"가 아니고, 바디는 [ADR 0010](0010-body-heaviness.md)
이후 CQI 전원 결측이다. 즉 오픈판에는 "강도(intensity)"를 사람이 매긴 라벨이 거의 없었다.

국내 로스터리 여러 곳은 상품 페이지에 자기 원두의 맛 게이지("산미 ●●●◐○", 막대 그래프, "산미 4.5│바디감 2")를
직접 공개한다. 로스터가 자기 원두를 직접 평가한 사람 라벨이고, 페이지의 사실 표기라 사실정보만 저장하는 원칙
(`pipeline/collect/roasters_kr.py`)과도 맞는다. LLM 추정은 예측기로 쓰지 않는다(데이터 레시피 공모전 — 데이터로 이겨야 한다).

## 결정
1. **게이지 수집** (`BeanFactRecord.gauge_acidity/body/sweetness/bitterness`, `gauge_scale`) — HTML 마크업이나 텍스트로
   보이는 게이지만 읽고 이미지 게이지는 읽지 않는다. 모든 사이트가 0~5, 반 단계 척도라 `normalize_gauge`는 5단계
   환산 후 [1, 5]로 자른다(반 칸 하나 = 1).

   | 사이트 | 게이지 보유/전체 | 척도(원문) | 속성 |
   |---|---|---|---|
   | 커피 리브레 | 18/33 | 점 5개, 반 점(●=1, ◐=0.5) | 산미·단맛 |
   | 1킬로커피 | 37/37 | SENSORY CHART 5칸 막대(`kg-sensory-fill/half/empty` 클래스) | 산미·단맛·쓴맛·바디 |
   | G로스팅 (신규, Cafe24) | 17/22 | og:description 숫자 0~5, 0.5 단위 | 산미·바디·단맛 (향미·균형은 버림) |
   | 내일의커피 (신규, imweb) | 10/10 | 점 5개, 반 점 | 산미·바디 |
   | 프릳츠·나무사이로·블루보틀·앤트러사이트·펠트·빈브라더스·모모스·매뉴팩트 | 0 | 산문 또는 이미지뿐 | — |

   표본으로 더 살펴본 로스터리(브라운체리·커피렉·로스팅타이거·원두반점·워너빈·포어르·커피그대로)는 상품 페이지에
   텍스트 게이지가 없어 제외했다. 합계 82건(산미 82 · 바디 64 · 단맛 72 · 쓴맛 37). G로스팅 페이지 소스에는 같은
   숫자의 막대 표가 HTML 주석 안에 남아 있지만 화면에 안 보이고 값이 낡은 경우가 있어(바디감 2.5 vs 표시값 2) 표시되는
   요약 줄만 읽는다.

2. **라벨 적재** — `normalize_roasters_kr`가 게이지가 있는 속성은 게이지를 라벨로 쓴다(DB는 정수라 반 단계는 올림,
   모델 학습은 `beans.jsonl`의 원래 소수 값). 새 컬럼 `coffees.attr_label_source`(jsonb, 속성별 `gauge` · `korean_cue` ·
   `llm_review` · `cqi_quality` · `review_score`)로 모든 라벨의 출처를 남긴다. CQI의 고도·품종과 로스터리가 표기한
   재배고도·품종은 `altitude_m`·`variety`로 노출한다.

3. **해석 가능한 특징 모델** (`app/core/featuremodel.py`, 학습 `scripts/train_feature_model.py`) — 특징: 산지 권역 원핫 +
   주요 5개국, 고도 4구간, 가공 4종, 로스팅 5단계, 품종(게이샤·SL), 디카페인 공정, 원두 자기 노트 단어의 SCA 대분류
   개수(`text_tags` 규칙 매퍼, 최대 3), 선택적으로 오픈 풀 이웃 평균 1개. 특징 추출 코드는 학습과 추론이 같은 함수를 쓴다.

4. **평가: 로스터리 단위 그룹 K-fold**(leave-one-roaster-out — 어떤 로스터리도 학습과 평가 양쪽에 있지 않음). 같은
   폴드·같은 대상에서 기준선과 비교한다. 이웃 평균 기준선도 대상과 같은 로스터리의 원두는 이웃에서 뺀다.

   | 속성 (n) | 전체 평균 | 산지 평균 | 오픈 이웃 평균 | 리지 | 리지+이웃 | GBT | GBT+이웃 |
   |---|---|---|---|---|---|---|---|
   | 산미 (82) ±1 / MAE | 0.524 / 1.033 | 0.512 / 1.022 | 0.500 / 1.122 | 0.622 / 0.863 | **0.658 / 0.923** | 0.634 / 0.832 | 0.671 / 0.816 |
   | 바디 (64) | 0.703 / 0.755 | 0.734 / 0.744 | 0.750 / 0.761 | 0.781 / 0.699 | 0.797 / 0.691 | 0.781 / 0.608 | 0.750 / 0.645 |
   | 단맛 (72) | 0.403 / 1.126 | 0.431 / 1.163 | 0.514 / 1.062 | **0.569 / 1.050** | 0.569 / 1.077 | 0.569 / 0.942 | 0.472 / 0.984 |

   이웃 평균 커버리지(유사 원두 3개 이상이 값을 가짐): 산미 0.99, 바디 0.36, 단맛 0.46 — 없으면 학습 폴드 평균으로 채웠다.
   CQI 산미(품질 5분위)를 가중치 0.2의 보조 라벨로 넣으면 산미 리지 ±1 0.622→0.634지만 MAE는 0.863→0.913으로
   나빠지고, GBT는 0.634→0.561로 무너진다 — 품질 점수는 강도 라벨을 대신하지 못해 보조 라벨은 쓰지 않는다.

5. **탑재 기준**: 리지(또는 리지+이웃) ±1이 오픈 이웃 평균보다 **0.05 이상** 높은 속성만 탑재. 산미(+0.159, 리지+이웃)·
   단맛(+0.056, 리지) 탑재, 바디(+0.047) 미탑재. GBT는 참고용 — 근거 문장이 특징별 기여도(가중치×값)로 설명해야 해서
   선형 모델만 싣는다. 탑재본은 게이지 원두 전체로 다시 적합해 `config/feature_model_open.json`(순수 파이썬 추론, numpy 없음).

6. **연결** (`app/graphs/analyze_bean.py`, 오픈판만) — 우선순위 **문구 단서 > 특징 모델 > 이웃 평균**. 모델이 없는 속성은
   이웃 평균 그대로, 임베딩이 실패한 저하 모드에서도 특징 모델은 동작(임베딩 불필요). 근거 한 줄:
   "특징 모델: 과일 노트·고지대(1,900m)·약배전 → 산미↑". `FEATURE_MODEL=off`로 끌 수 있다.

## 해석 (최종 적합 리지 가중치)
- 산미: 과일 노트 +0.41, 고지대(1,600~2,000m) +0.32, 약배전 +0.26, 동아프리카 +0.22, 에티오피아 +0.19 /
  견과·초콜릿 노트 −0.37, 중강배전 −0.37, 강배전 −0.22, 과테말라 −0.19. 이웃 평균 +0.13.
- 단맛(원래 척도가 로스터리마다 가장 다름): 블렌드 +0.68, 2,000m 이상 +0.67, 허니 +0.67, 워시드 +0.62, 강배전 +0.55,
  물 공정 디카페인 −0.53.
- GBT 중요도 상위: 산미 = 이웃 평균·과일 노트·중강배전·동아프리카, 바디 = 에티오피아·강배전·중배전·견과·초콜릿 노트.

## coffeereview 대조 (평가 전용, 학습에 쓰지 않음)
이웃 특징 없는 리지를 전체판 coffeereview 원두에 적용: 산미(리뷰 서브스코어 5분위) Spearman **0.24**, 바디(LLM 무게감)
Spearman **0.03**. MAE/±1은 전체 평균보다 나쁘다(산미 1.13/0.47 vs 0.82/0.71) — 척도가 다르고(5분위는 균등 분포,
게이지는 로스터리 관행) 영어 리뷰 요약에는 한국어 노트 매퍼가 덜 걸리기 때문. 산미의 **방향**은 옮겨 가고, 바디는
옮겨 가지 않는다는 뜻으로 읽는다.

## 한계
- 라벨 82건·로스터리 4곳뿐이라 폴드 하나가 로스터리 하나다 — 척도 관행이 로스터리마다 다르고(1킬로커피는 단맛을 전반적으로
  낮게, 커피 리브레는 높게 매김) 그 차이가 오차의 큰 몫이다. 단맛의 +0.056은 72건 중 4건 차이로 기준선을 겨우 넘었다.
- 후보 선택(리지 vs 리지+이웃)을 같은 CV 결과로 골라 약간 낙관적이다. 두 후보 모두 산미에서는 기준선을 넘는다(+0.12/+0.16).
- 디카페인·게이샤처럼 표본이 몇 개뿐인 특징의 가중치는 잡음에 가깝다(예: 슈가케인 디카페인 → 산미↑).
- 1킬로커피 원두에는 노트 단어가 없어(사이트가 산문으로만 표기) 노트 특징이 0이다.

## 후속: 프랜차이즈 브랜드 원두 (2026-09-28)
오픈판의 브랜드 원두 값(`brands.yaml` `bean_open`/`decaf_bean_open`)도 이 특징 모델로 산미·단맛을 채운다 — 공식
문구의 명시적 단서가 먼저, 그다음 이 모델(공식 산지/블렌드·로스팅·디카페인 공정·공식 향미 단어만 입력, 이웃 없음),
없으면 손 추정. 전체판 학습 모델(coffeereview 라벨)은 오픈판 브랜드 값에 쓰지 않는다. 표와 한계는
[ADR 0012 오픈판 브랜드 값](0012-official-brand-beans.md#오픈판-브랜드-값).

## 후속: 오픈 라벨 늘리기 (2026-09-28)
Shopify 로스터 강도 표기(A), 노트 단어 약한 라벨(B), 로스터 보정(C)을 같은 그룹 CV로 절제 실험했다. **산미만** 약한
라벨(재중심, 가중치 0.3)을 더한 모델로 교체(±1 0.658→0.695, MAE 0.923→0.771), 단맛·바디는 그대로다. A의 겉보기
이득(0.768)은 "고도 표기 → 밝음"이라는 가게 페이지 형식 지름길이라 쓰지 않았다. 표와 근거는
[ADR 0013](0013-open-labels-weak-supervision.md).

## 후속: 외부 패널 점검 (2026-09-28)
Zenodo Q그레이더 패널(196샘플, 평가 전용)에서 같은 표본끼리 비교했다([ADR 0014](0014-public-sources-ediya-twosome-kca-zenodo.md#오픈판-단맛-특징-모델-vs-이웃-평균-같은-표본-2026-09-28)).
산미 머리는 이웃 평균·상수 3을 모두 이긴다(n=184, MAE 0.62 vs 0.91, Spearman 0.62 vs 0.49). 단맛 머리(CV +0.056)는
이웃 평균보다 MAE는 낫고(1.32 vs 1.52) Spearman은 나쁘다(−0.26 vs 0.01) — "MAE·Spearman 모두 나쁘면 뺀다"는 미리 정한
규칙에 걸리지 않아 **유지**하지만, 두 예측기 모두 상수 3(MAE 0.62)에 크게 지고 순위 정보가 없다. 외부 증거가 CV 이득보다
우선한다는 원칙은 그대로이며, 단맛 머리는 "로스터리 게이지 관행의 재현"으로만 읽는다.

`shopify_gauged` 적재 뒤 풀에서 다시 잰 게이지만 CV(`phase3_feature_model.json`, 2026-09-28): 이웃 평균이 좋아져(산미
0.524, 단맛 0.542, 바디 0.766) 게이지만 규칙(+0.05)으로는 산미(리지 +0.098)만 통과하고 단맛은 +0.028이다. 단맛 사양은
ADR 0013의 "유지" 결정과 ADR 0014의 외부 점검 규칙에 따라 그대로 싣는다 — 탑재 여부는 스크립트 재실행이 아니라
`SHIPPED_RECIPES`로 정한다.
