# AI 엔지니어링 깊이 — 설명 품질 평가·결정적 검색·운영 관측 구현 계획

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** LLM 설명의 품질을 숫자로 증명하고(규칙 검사 + 판정자 2개), 이웃 검색을 결정적으로 만들어 평가를 재현 가능하게 하며, 운영 요청의 지연·폴백을 로그로 재서 README에 싣는다.

**Architecture:** 평가는 전부 `app/eval.py`의 커맨드로 추가(`explain_quality`, `loo_repro`, `prod_stats`는 별도 스크립트). 규칙 검사는 순수 함수 모듈 `app/core/explain_check.py`. 텔레메트리는 `contextvars` 기반 `app/telemetry.py`가 그래프 노드에서 타이밍을 모아 스트림 끝에 JSON 한 줄을 로깅한다. 앱 응답 형식은 바뀌지 않는다.

**Tech Stack:** Python 3.12, httpx, pydantic, pytest, Postgres/pgvector, NVIDIA API(nemotron, deepseek-v4.1-flash), Render Logs API.

**Spec:** `docs/superpowers/specs/2026-09-27-ai-depth-design.md`

## Global Constraints

- pytest는 LLM·네트워크를 부르지 않는다(판정·생성은 `python -m app.eval …` 커맨드에서만). 결과 JSON은 `data/eval/`에 커밋.
- 로그·평가 JSON에 프로필 수치 외의 개인 데이터(후기 원문, 닉네임, 사용자 id)를 넣지 않는다. 케이스 세트는 손으로 만든 가상 손님이다.
- 판정자는 `config/models.yaml`의 `judge`(deepseek-v4.1-flash)와 `judge2`(nemotron) 태스크를 그대로 쓰되 둘 다 thinking을 끈다(`judge2`에 `extra: {chat_template_kwargs: {enable_thinking: false}}`; deepseek은 이미 non-thinking이면 그대로).
- 커밋 메시지 한국어 conventional + 세션 트레일러. `uv run pytest -q` 전부 통과 후 커밋.

## Review Focus

- **판정자가 페이로드에 있는 숫자를 "환각"으로 오판** → 판정 프롬프트에 페이로드 전체를 사실 목록으로 주고, 규칙 검사 `numbers_grounded`가 독립적으로 같은 판단을 한다(Task 1·2 테스트).
- **폴백(템플릿) 설명이 판정에 섞여 점수를 부풀림** → 결과에 `fallback: true`를 남기고 합격률은 LLM 생성분만으로 따로 계산(Task 2).
- **`ORDER BY …, id` 추가가 HNSW 인덱스 사용을 깨뜨림** → `EXPLAIN`으로 인덱스 스캔 유지 확인, `neighbors` 지연 전후 측정(Task 3).
- **텔레메트리가 스트림을 느리게 하거나 예외로 죽임** → 로깅은 `done` 뒤 한 번, 예외는 삼킨다(Task 5 테스트: 로거가 던져도 스트림 정상).
- **Render 로그 API 페이지네이션·시간창** → 스크립트가 `hasMore`/cursor를 따라가고, 창 안의 요청 수를 로그 줄 수와 대조(Task 6 테스트: 픽스처 2페이지).

```python
"""Deterministic checks on a generated explanation: no LLM, no network. Used by `app.eval explain_quality`."""
import re

MAX_SENTENCES, MAX_CHARS = 3, 220
POSITIVE = ("잘 맞", "추천해", "딱 맞", "어울려요", "잘 어울")
NEGATIVE = ("맞지 않", "어울리지 않", "거리가 있", "안 맞")
CONDITION_WORDS = ("디카페인", "카페인", "우유")
_LATIN = re.compile(r"[A-Za-z]{2,}")
_NUM = re.compile(r"\d+(?:\.\d+)?")


def payload_numbers(payload: dict) -> set[float]:
    out: set[float] = set()

    def walk(v):
        if isinstance(v, bool):
            return
        if isinstance(v, (int, float)):
            out.add(float(v))
        elif isinstance(v, dict):
            for x in v.values():
                walk(x)
        elif isinstance(v, list):
            for x in v:
                walk(x)
        elif isinstance(v, str):
            for m in _NUM.findall(v):
                out.add(float(m))
    walk(payload)
    return out


def check_explanation(text: str, payload: dict, score: int, violation: str | None) -> dict[str, bool]:
    allowed = {w.lower() for tag in payload.get("향미", []) for w in _LATIN.findall(str(tag))}
    allowed |= {"mg", "hot", "iced", "ice"}
    foreign_ok = all(w.lower() in allowed for w in _LATIN.findall(text))
    sentences = [s for s in re.split(r"[.!?]\s*", text) if s.strip()]
    length_ok = len(sentences) <= MAX_SENTENCES and len(text) <= MAX_CHARS
    nums = payload_numbers(payload) | {float(score)}
    numbers_ok = all(any(abs(float(n) - p) <= 0.05 for p in nums) for n in _NUM.findall(text))
    condition_ok = (not violation) or any(w in text for w in CONDITION_WORDS)
    if score < 40:
        polarity_ok = not any(w in text for w in POSITIVE)
    elif score >= 80:
        polarity_ok = not any(w in text for w in NEGATIVE)
    else:
        polarity_ok = True
    return {"foreign_words": foreign_ok, "length": length_ok, "numbers_grounded": numbers_ok,
            "condition_mentioned": condition_ok, "polarity": polarity_ok}


def all_ok(result: dict[str, bool]) -> bool:
    return all(result.values())
```
